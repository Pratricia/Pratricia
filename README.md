# Hi, I'm Pratricia

Building small, zero-dependency web apps you can just open and run. Currently learning open-source collaboration through Drips Wave.

## Things I've built

- **[image-sonata](https://github.com/Pratricia/image-sonata)** - Turn a photo into a 90-second tune. Image features drive procedural composition and sample-based singing synthesis. Zero dependencies, single page.
- **[zh-search-bench](https://github.com/Pratricia/zh-search-bench)** - A reproducible benchmark for Chinese full-text search: 15 configurations, 727 queries, recall data you can check.
- **[shoushuai](https://github.com/Pratricia/shoushuai)** - Chinese-chess-themed merge tower defense. 50 stages, endless mode, two-player. [Play it](https://pratricia.github.io/shoushuai/).
- **[thu-bdc2026-stock-ranking](https://github.com/Pratricia/thu-bdc2026-stock-ranking)** - Learning-to-Rank for A-share stock selection (StockTransformer + multi-objective ranking loss).
